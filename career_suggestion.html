03 — Matching Answers With Careers 
if A == 1:
    careers["Technology & IT"] += 1

elif A == 2:
    careers["Healthcare & Medicine"] += 1

elif A == 3:
    careers["Business & Finance"] += 1

elif A == 4:
    careers["Arts & Design"] += 1

elif A == 5:
    careers["Education & Teaching"] += 1

elif A == 6:
    careers["Engineering"] += 1

elif A == 7:
    careers["Media & Communication"] += 1

elif A == 8:
    careers["Psychology & Social Services"] += 1
04 — Finding The Highest Score 
heighest_score = max(careers.values())

for career, score in careers.items():

    if score == heighest_score:
        print("-", career)
How the logic works:

Every career starts with a score of 0. Each answer is connected to one career domain. Whenever the user selects an option, that career receives +1 point.

After all 8 questions are answered, the program checks which career has the highest score using Python's max() function.

If two or more careers have the same highest score, the system displays all of them as possible suggestions.
